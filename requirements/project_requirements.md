# Learning Management System (LMS)

## Problem Statement
Many schools and training institutions struggle to manage students, courses, assignments, and grades efficiently.

## Business Requirements
- Manage students
- Manage instructors
- Manage courses
- Track enrollments
- Record grades

## Functional Requirements
- Student registration
- Course creation
- Assignment submission
- Grade management

## Non-Functional Requirements
- Security
- Scalability
- Performance
- Reliability

## User Roles
- Admin
- Instructor
- Student

## Assumptions and Constraints
- PostgreSQL is the primary database
- Redis is used for caching
